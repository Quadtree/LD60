THEME: Old Tech

The obvious interpretation is one of those neo-retro games, designed to look like a classic game.

I should make this a total retro-retro game where you have to read the manual, and call it "Manual Fighter".

The idea is that it's a sort of elite-inspired game where you fly around in a spaceship, with incredibly low poly untextured graphics.


- You have to type the right load command to start the game. To help the player figure this out, the manual will start opened to the right page.
- When you press Enter to start the game, it starts with tedious copy protection. This introduces the idea of flipping through the manual.
- You start out on an extremely low-poly space station. You have to walk to your ship and press E.
- Once in space you can steer by using WASDEQ/Space/Shift

The plot of the game is pretty simple. You start on Silver Station. A case of gems belonging to Interdimensional Mining Corp. that you were supposed to be transporting has been stolen by pirates in the night.

The game immediately tells you that you need to get to Bronze station, since it's supposedly a pirate haven. It doesn't give you coordinates or anything, though. That's all in the manual.

Upon visiting Bronze Station, you get in a fist fight with a pirate robot, since all classic games must have janky half-baked mechanics. It's resolved with rock-paper-scissors, (uppercut, feint, lunge), but it's pretty hard without the manual, because the robot has twice your health. The manual all but tells you how to win, because the robot has a clear pattern.

Once you beat the robot, it's time for more copy protection! The robot drops a note written in a SUPER SEKRET PIRATE KODE, a key to which is in the manual.

At that point, you simply need to go to the pirate station and blow it up. Convienently, the case will survive the explosion and you win.
